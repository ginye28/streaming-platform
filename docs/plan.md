# 계획 설계서 (plan.md)

## 0.주제 변경 사유
처음에는 클라이밍 완등 기록 웹앱을 계획했지만, 2026-07-29부터 만들어 온 라이브 스트리밍 플랫폼(SP)이 이미 배포 단계까지 와 있어서 이쪽을 완성도 높이는 쪽으로 바꿨다.

## 1.한 줄 소개
방송을 실시간으로 보고 채팅·구독·후원까지 되는 라이브 중심 스트리밍 플랫폼. 웹은 Vercel, API는 Render, DB는 TiDB(MySQL 호환)에 무료로 배포했다.

## 2.누구를 위한 것인가
방송을 하며 채팅 운영과 구독·후원 수익을 관리하고 싶은 개인 스트리머, 채널을 구독하고 라이브 채팅에 참여하며 다시보기로 보고 싶은 시청자.

## 3.핵심 기능 3가지
1. **라이브 방송·시청:** OBS(RTMP→HLS) 방송, 웹에서 화면 공유/카메라로 바로 방송, 방송 예약·대기실, 다시보기와 채팅 리플레이.
2. **실시간 채팅과 운영:** WebSocket 채팅, 매니저·금칙어·채팅 제한·슬로우 모드·공지 고정.
3. **수익화:** 토스페이먼츠 테스트 키로 유료 구독(1·3·6·12개월)·후원·환불·정산 내역, 멤버십 전용 방송.

- 카드 결제 후 돌아올 때 404가 뜨던 문제 수정

## 6.알려진 한계
- 무료 서버라 첫 요청이 느리고 동시 웹 방송은 1개
- 웹 방송은 다시보기가 남지 않는다.
- 슬로우 모드·시청자 수는 서버 메모리 기반이라 서버를 여러 대로 늘리기 어렵다.
