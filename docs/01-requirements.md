# 요구사항 명세서

혼자 쓰는 개인 스트리밍 사이트입니다. 치지직·유튜브에서 필요한 것만 골라 만들었습니다.
직접 올린 영상(VOD)을 보는 쪽과, OBS 로 실시간 송출하는 쪽 **둘 다** 있습니다.

만들어진 것과 안 만들어진 것은 [README 의 구현 상태](../README.md#구현-상태) 가 최신입니다.
이 문서는 "무엇을 왜 만들기로 했나" 를 적어 둔 것입니다.

---

## 기능 요구사항

### 회원

- 회원가입 · 로그인 · 로그아웃
- 액세스 토큰이 만료되면 리프레시 토큰으로 다시 받기
- 내 정보 조회 · 수정 · 비밀번호 변경
- 관리자 권한 (설정으로 첫 관리자를 만들고, 그다음부터는 API 로 승격)

### 영상 (VOD)

- 영상 올리기 · 수정 · 삭제
- 목록 (최신순 · 인기순), 카테고리로 거르기, 제목·설명 검색
- 조회수 — **같은 시청자는 30분에 한 번만** 셉니다.
  로그인했으면 계정으로, 아니면 접속 IP 로 구분합니다.
- 좋아요
- 썸네일 — 영상을 올리면 첫 장면을 자동으로 뽑습니다. 직접 골라도 됩니다.

### 댓글

- 댓글 달기 · 수정 · 삭제
- 답글 — **두 단계까지만.** 답글에 답글은 못 답니다.
  더 깊어지면 화면에서 읽기 어려워서 일부러 막았습니다.

### 라이브

- OBS 로 RTMP 송출 → HLS 로 재생
- **스트림 키가 재생 URL 에 드러나면 안 됩니다.** 송출을 공개 이름으로 바꿔서 내보냅니다.
- 방송 중 목록 · 방송 상세 · 지난 방송 이력
- 실시간 채팅 (WebSocket) 과 채팅 저장
- 동시 시청자 수와 그 방송의 최고 시청자 수

### 채널 · 관계

- 채널 페이지 (그 사람의 영상 · 방송 이력 · 지금 방송 중인지)
- 구독, 구독한 채널들의 영상 피드
- 차단 — 차단하면 그 사람 영상이 목록과 피드에서 빠집니다.

### 알림

- 구독한 채널이 방송을 시작했을 때
- 내 영상에 댓글이 달렸을 때
- 내 댓글에 답글이 달렸을 때

자기가 자기한테 보내는 알림은 남기지 않습니다.

### 신고 · 관리

- 사용자 · 영상 · 댓글 · 방송 신고
- 관리자 화면 — 신고 처리, 카테고리 만들기, 사용자 권한 바꾸기

## 비기능 요구사항

| | |
|---|---|
| 인증 | JWT (액세스 + 리프레시). 리프레시 토큰은 **해시만** 저장 |
| 비밀번호 | BCrypt |
| 응답 형태 | `{ success, data, message }` 로 통일 |
| 페이지 | 크기 상한 100 |
| 파일 업로드 | 100MB 까지, 확장자 화이트리스트 |
| 스키마 | Flyway 마이그레이션. Hibernate 는 `validate` 로 확인만 하고 표를 손대지 않음 |
| 배포 | Docker 이미지 세 개 + GitHub Actions (빌드까지. 서버에 올리는 건 아직 손으로) |

### 일부러 안 넣은 것

- **Redis** — 시청자 수 · 조회수 중복 판정 · 채팅 브로커가 전부 서버 메모리에 있습니다.
  서버 한 대에서는 맞고, 여러 대로 늘릴 때 필요해집니다. 지금은 한 대라 안 넣었습니다.
- **소셜 로그인** — `users.provider` 칸만 만들어 두고 아직 안 씁니다.
