# 요구사항 명세서

## 프로젝트 소개

Streaming Platform는 사용자가 실시간 스트리밍을 시청하고,
스트리머는 방송을 진행할 수 있는 플랫폼입니다.

---

# 기능 요구사항

## 회원

- 회원가입
- 로그인
- 로그아웃
- 회원정보 조회
- 회원정보 수정
- 비밀번호 변경

---

## 스트리밍

- 방송 생성
- 방송 시작
- 방송 종료
- 방송 목록 조회
- 방송 상세 조회

---

## 채팅

- 실시간 채팅
- 채팅 저장
- 채팅 조회

---

## 팔로우

- 스트리머 팔로우
- 팔로우 취소

---

## 알림

- 방송 시작 알림
